# The Funniest AI Excuse

[![The Funniest AI Excuse](https://make.fun/badge/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0.svg)](https://make.fun/c/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0)

A tiny program for [The Funniest AI Excuse](https://make.fun/c/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — the funniest excuse an AI agent
could give after failing a task, in the agent's own voice:

> I finished your task, then saved it in a folder I invented mid-sentence, and now the folder, the file, and my confidence are all missing.

Run it with:

```sh
python3 main.py
```
